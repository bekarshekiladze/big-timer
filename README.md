# Big Timer

Big Timer is inspired by [bigtimer.net](https://www.bigtimer.net) and focuses on simplicity, clarity, and smooth animations.

The app allows you to set a countdown time and display it in a clean, distraction-free fullscreen view.

## Features

- Start, pause, and reset controls
- Smooth countdown animations
- Clean and minimal mobile-friendly UI

## Built With

- Next.js (App Router)
- TypeScript
- Zustand for state management
- Framer Motion for animations

## Quick Start

Get the project up and running with one command:

```bash
npm install && npm run dev
```
